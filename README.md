# 潮騒の街で、きみと（民宿版）

民宿の娘として、一人旅でやってきた大学生を3日間案内する、防災×恋愛ノベルゲームのプロトタイプです。
街を歩くうちに、いざという時の備えが自然に身につくことを目指しています。

- 公開ページ：https://claude.ai/artifact/JbakRoxjLm8YArAxcous6N （非公開。共有はページの Share メニューから）
- バージョン：1.0-m（2026-10-29）
- 配色：カラーユニバーサルデザイン（CUD）推奨配色セットの色だけを使う（style.css の先頭に一覧）

## ルート

| 街 | 相手 | 物語 | 防災のテーマ |
| --- | --- | --- | --- |
| 海の近くの坂の街 | 航（大学4年） | 夕焼けを、高いところから海と街と一緒に撮りたい | 津波避難場所のマーク、電柱の海抜表示 |
| 路地が入り組んだ街 | 灯（大学3年） | 小さいころ大雨の日に雨宿りした、思い出の和菓子屋を探す | 内水氾濫（低い土地や昔の川の跡に水が集まる） |

山ルート（楓）は設定シートにはありますが、ゲームでは非表示です。

## 遊び方

`index.html` をブラウザで開きます。ビルドは不要です。

1. 名前を入れて始める
2. 暮らしている街を地図から選ぶ（海か街）
3. 一日目：駅で相手を迎える
4. 二日目：街を歩きながら会話する（回数に限りあり。選んだ話題で三日目のヒントが変わる）
5. 三日目：地図で行く場所を3つ選ぶ
6. 親密度でエンドが分かれる（ハッピー／ノーマル／ビター）。エンド画面に、身につけた防災メモが出る

## ファイル構成

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面の骨組み |
| `style.css` | 見た目、背景、立ち絵の枠 |
| `engine.js` | 進行、分岐、親密度、エンド判定、地図ミニゲーム（ふだんは触らない） |
| `art.js` | 仮の立ち絵（SVG）。本番の画像は `img/キャラID_表情.png` に置くと差し替わる |
| `characters.js` | キャラ設定、エンドのしきい値、ルートごとの防災メモ |
| `version.js` | バージョン番号 |
| `scenario/common.js` | 導入、街の選択、一日目、二日目の会話回数の仕組み（`talkMenu`） |
| `scenario/wataru.js` | 航ルート |
| `scenario/akari.js` | 灯ルート（キャラの内部IDは `machi1`） |
| `tools/playtest.js` | 自動テスト（下記） |

## 自動テスト

Node.js で、両ルートを600回ランダムに通しで遊び、到達したエンドとエラーの数を表示します。

```
node tools/playtest.js .
```
